## `whoami` 👋

I'm **Aaditya**, a Cloud Platform Engineer focused on building and operating secure, reliable, and cost-aware cloud-native platforms.

- ☁️ Working with **AWS**, especially **EKS, VPC, EC2, IAM, and load balancing**.
- ☸️ Focused on **Kubernetes platform engineering**, cluster networking, workload security, and production operations.
- 🕸️ Exploring advanced networking and service connectivity with **Cilium** and **Istio**.

- ⚙️ Automating repeatable platform tasks with **Linux, Bash, Python, Helm, and GitOps tools**.
- 🎯 My goal: make infrastructure **secure, scalable, observable, and cost-efficient**.
